# CHUD architecture

The first milestone implements a C++20 frontend with a lexer, recursive-descent parser, source-spanned AST, scoped symbol resolution and static type checking during LLVM IR lowering. LLVM's command-line backend compiles the IR into an object, then links it with a small C runtime into a native executable. No source-language transpilation or interpreter is involved. Textual LLVM IR keeps the frontend independent of LLVM C++ library versions; embedding those libraries is a future improvement.

`chudc` owns language semantics. The Node-based project CLI and language server invoke it rather than reimplementing a parser. `chud.exe` is a native launcher for the CLI. CHUD Studio is an Electron main process with a sandboxed React/Monaco renderer and a narrow preload API. Build and terminal processes run only in the selected workspace. AI replies are text, never executable commands.

Discord Rich Presence belongs to Studio's main process. The public application identifier in `studio/electron/discord-identity.cjs` supplies CHUD Studio's registered identity; no credentials are bundled. Persisted settings control enabling it, project/filename visibility, elapsed time, and an optional advanced custom application. It defaults off. Legacy custom IDs migrate without losing the user's configuration. The local IPC client handles framing, retries, throttling, errors and clearing presence. Neither credentials nor source text are sent to Discord. Protocol reference: https://github.com/discord/discord-rpc/blob/master/documentation/hard-mode.md

Milestone order: native compiler; useful project CLI; actual Studio editing/build/run; Discord settings; compiler-backed LSP diagnostics; verified ChudGPT adapters. Advanced types, packages and native debugging follow after this foundation. No controls should imply those later features are implemented.

The native library catalog in `runtime/builtins.def` is the common source of compiler signatures and editor/LSP completion. CHUD bool values cross the native ABI as C int; opaque integer lists and immutable strings use process-lifetime allocations with a 64 MiB budget. Win32/GDI owns and releases the single immediate-mode GUI window and its backing surface. The GUI library follows an explicit Open/BeginFrame/EndFrame/Close loop.

Studio's Basic assistant is a deterministic, local source-template tool with preview and reviewed replacement, not an AI fallback. It has no model/network dependency. File/Edit/View/Build/Tools menus dispatch fixed commands through the preload event channel; the renderer only selects from implemented handlers. The separate ChudGPT tab retains the existing adapters and privacy controls.
